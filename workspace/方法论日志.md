# 方法论日志

**定义**：记录工作方法论的版本演变。

**解决**：方法论改了却无从追溯，无法回退。

**目标**：支持版本对比与一键复原。

### 使用规则

- 任何对 `全局工作台.md` / `新项目流程.md` / `agent.md` / `复利与踩坑.md` / `工程的原则.md` 的规则改动，都在此记一笔。
- 每条记录含：版本号、日期、改动摘要、影响范围、原因。
- 旧版本内容保留，便于对比与复原。完整旧版见 `Workspace/` 下的备份文件。
- 版本号规则：主版本号改动规则结构，次版本号改动单条规则或补缺。

### 更新节奏

回顾时间由用户指定：首次使用时询问用户偏好的提醒时间（默认建议：每周五 14:00 提示用户回顾并更新）。
